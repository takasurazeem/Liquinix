Liquinix - install
(Português: o LiquinixSetup.exe aparece em português num Windows em português.)

1. Extract this .zip to any folder (e.g. Downloads\Liquinix).
2. Open LiquinixSetup.exe. If Windows says "Windows protected your PC", click
   "More info" > "Run anyway" (the program isn't code-signed yet).
3. Pick what to install: the full Liquinix, only the apps, only the Mac title bars, or apps + title bars.
   The installer follows your Windows language (English or Portuguese).

Update: Settings > General > Software Update > Update Now (or run LiquinixSetup.exe again).
Uninstall: Windows Settings > Apps > Installed apps > Liquinix > Uninstall (your settings can stay).

Shortcuts: Spotlight Win+Space, Launchpad Win (tap), Mission Control Win+Tab, app switcher Alt+Tab.
Quit Liquinix: Ctrl+Alt+Shift+F12. Emergency (brings back Explorer): Ctrl+Alt+Shift+F11.

Installs to %LOCALAPPDATA%\Programs\Liquinix (no administrator needed). Settings: %APPDATA%\Shell.
The old scripts (instalar.cmd, atualizar.cmd, desinstalar.cmd) still work.

Requires Windows 11 (22H2 or newer).
Mac icons, sounds, fonts and cursor belong to Apple: personal use only, on your own PCs.
